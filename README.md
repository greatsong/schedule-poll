# [💕 우리 언제 만나? — 시간 약속 투표 앱(https://greatsong.github.io/schedule-poll/)](https://greatsong.github.io/schedule-poll/)

> 선생님들 간 시간 약속을 잡기 위한 **실시간 투표 웹앱**입니다.
> 링크 하나로 접속해서 가능한 시간을 탭하면, 모든 사람의 결과가 실시간으로 모입니다.

---

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 📅 시간 투표 | 월요일부터 금요일, 0교시부터 8교시 + 점심시간 중 가능한 시간을 탭 |
| 🏆 베스트 시간 | 가장 많은 사람이 가능한 시간을 자동 하이라이트 |
| 🔔 미투표 알림 | 아직 투표 안 한 사람이 누구인지 표시 |
| 🔄 실시간 동기화 | 한 명이 투표하면 다른 사람 화면에 즉시 반영 |
| 🎨 6가지 테마 | 러블리 핑크, 체리블라썸, 피치 코랄, 라벤더 드림, 오션 블루, 포레스트 그린 |
| 🔗 초대 링크 | 비밀 키가 포함된 링크로 투표에 초대 (테마 정보도 포함) |
| 🔒 관리자 비밀번호 | 투표 생성 시 비밀번호를 설정하면 본인만 마감 가능 |
| 📦 투표 마감 | 완료된 투표를 마감하면 홈 화면 하단으로 보관 |
| ♻️ 재사용 | 새 투표를 계속 만들 수 있어서 다른 그룹과도 사용 가능 |

## 🚀 처음부터 끝까지 세팅 가이드

### 준비물

- **Google 계정** 1개 (Gmail이면 됩니다)
- **GitHub 계정** 1개 ([github.com](https://github.com) 에서 무료 가입)
- 이 저장소의 `index.html` 파일

> 💡 **비용은 전혀 들지 않습니다.** Firebase 무료 플랜 + GitHub Pages 무료 호스팅으로 충분합니다.

---

### 📌 1단계: Firebase 프로젝트 만들기

1. [Firebase Console](https://console.firebase.google.com/)에 접속합니다
2. Google 계정으로 로그인합니다
3. **"프로젝트 추가"** (또는 "Add project") 버튼을 클릭합니다
4. 프로젝트 이름을 입력합니다 (예: `schedule-poll`)
5. Google 애널리틱스 설정 → **끄고** 넘어가도 됩니다
6. **"프로젝트 만들기"** 클릭 → 잠시 기다리면 완료!

> ✅ **체크포인트:** "프로젝트가 준비되었습니다" 메시지가 보이면 성공

---

### 📌 2단계: Realtime Database 만들기

1. Firebase Console 왼쪽 메뉴 → **"빌드"** → **"Realtime Database"** 클릭
2. **"데이터베이스 만들기"** 버튼 클릭
3. **위치:** `싱가포르 (asia-southeast1)` 선택 (한국에서 가장 빠름)
4. **보안 규칙:** **"테스트 모드에서 시작"** 선택
5. **"사용 설정"** 클릭

> ✅ **체크포인트:** 빈 데이터베이스 화면이 보이고, 상단에 `https://프로젝트명-default-rtdb.asia-southeast1.firebasedatabase.app/` URL이 보이면 성공

---

### 📌 3단계: 보안 규칙 설정하기

> ⚠️ 이 단계를 건너뛰면 30일 후 데이터 읽기/쓰기가 차단됩니다!

1. Realtime Database 페이지에서 **"규칙"** 탭 클릭
2. 기존 내용을 **전부 지우고** 아래 내용을 **복사해서 붙여넣습니다:**

```json
{
  "rules": {
    "polls": {
      ".read": true,
      ".write": true
    },
    "votes": {
      ".read": true,
      ".write": true
    }
  }
}
```

3. **"게시"** (Publish) 클릭

> ✅ **체크포인트:** "규칙이 게시되었습니다" 메시지가 나오면 성공

---

### 📌 4단계: 웹 앱 등록 & 설정값 복사

1. Firebase Console 좌측 상단 ⚙️ **톱니바퀴** → **"프로젝트 설정"**
2. 아래로 스크롤 → **"내 앱"** 섹션에서 **웹 아이콘 (`</>`)** 클릭
3. 앱 닉네임 입력 (예: `schedule-poll`) → **"앱 등록"**
4. 화면에 나오는 `firebaseConfig` 값을 복사합니다

> ⚠️ **`databaseURL` 줄이 반드시 포함되어야 합니다!**
> 빠져 있다면 2단계에서 확인한 URL을 직접 추가하세요.

> ✅ **체크포인트:** `apiKey`, `databaseURL` 등이 포함된 설정값을 복사했으면 성공

---

### 📌 5단계: index.html에 설정값 붙여넣기

1. `index.html`을 텍스트 편집기(메모장, VS Code 등)로 엽니다
2. 상단의 `firebaseConfig` 부분을 찾아 복사한 값으로 교체합니다
3. 저장합니다 (`Ctrl+S` 또는 `Cmd+S`)

> ✅ **체크포인트:** `index.html`을 브라우저에서 열었을 때 (더블클릭) "우리 언제 만나?" 화면이 나오면 성공!

---

### 📌 6단계: GitHub에 올리기

#### 방법 A: 웹에서 직접 (가장 쉬움!)

1. [GitHub](https://github.com) → 우측 상단 **`+`** → **"New repository"**
2. Repository name: `schedule-poll`
3. **Public** 선택 → **"Create repository"**
4. **"uploading an existing file"** 링크 클릭
5. `index.html` 파일을 **드래그 앤 드롭** → **"Commit changes"**

#### 방법 B: 명령어 사용

```bash
git init
git add index.html README.md
git commit -m "시간 약속 투표 앱"
git branch -M main
git remote add origin https://github.com/본인아이디/schedule-poll.git
git push -u origin main
```

---

### 📌 7단계: GitHub Pages 배포 (마지막!)

1. GitHub 저장소 → **Settings** 탭
2. 왼쪽 **"Pages"** 클릭
3. Branch: **`main`** / **`/ (root)`** 선택 → **Save**
4. 1-2분 후 URL 생성:

```
https://본인아이디.github.io/schedule-poll/
```

> 🎉 **이 URL을 선생님들께 공유하세요!**
> 단, 초대 링크 기능을 사용하면 더 편리합니다 (아래 참고).

## 📱 사용 방법

### 투표 만들기

1. 홈 화면에서 **투표 제목**과 **참여자 이름**을 입력합니다
2. **관리자 비밀번호**를 설정합니다 (선택사항이지만 권장)
   - 비밀번호를 설정하면 **본인만** 투표를 마감할 수 있습니다
   - 설정하지 않으면 누구나 마감할 수 있습니다
3. **"투표 시작하기"** 클릭!

### 선생님들 초대하기

1. 투표를 만들면 **초대 링크**가 자동으로 생성됩니다
2. 선생님 선택 화면의 🔗 초대 링크 영역에서 **"복사"** 버튼 클릭
3. 카카오톡, 문자, 이메일 등으로 링크를 공유합니다
4. 링크를 받은 선생님은 클릭만 하면 **바로 해당 투표로 이동**합니다

> 💡 초대 링크에는 **비밀 키**와 **현재 테마** 정보가 포함됩니다.
> 받는 분도 보내는 분과 같은 테마로 처음 열립니다!

### 투표하기

1. 선생님 성함을 선택합니다
2. 가능한 요일/교시를 **탭** (다시 탭하면 취소)
3. 투표는 **자동 저장** — 별도 제출 버튼 없음!

### 결과 확인

- 🏆 가장 많은 선생님이 가능한 시간이 하이라이트됩니다
- 🔔 아직 투표하지 않은 선생님이 표시됩니다
- 각 칸에 누가 가능한지 이름이 나옵니다
- **실시간 자동 업데이트** — 새로고침 필요 없음!

### 투표 마감하기

1. 선생님 선택 화면 하단의 **"📦 투표 마감"** 버튼 클릭
2. 관리자 비밀번호가 설정된 경우 **비밀번호 입력** 필요
3. 마감된 투표는 홈 화면에서 사라지고, **"📦 마감된 투표"** 섹션에 보관됩니다
4. 마감된 투표를 열면 **"📋 다시 열기"** 버튼으로 복구할 수 있습니다

### 테마 바꾸기

상단의 이모지/아이콘 버튼으로 6가지 테마를 변경할 수 있습니다:

| 테마 | 특징 |
|------|------|
| 💕 러블리 핑크 | 따뜻한 분홍 톤 (기본) |
| 🌸 체리블라썸 | 진한 핑크, 봄 느낌 |
| 🟠 피치 코랄 | 따뜻한 코랄 오렌지 (커스텀 아이콘) |
| 🟣 라벤더 드림 | 보라색 크리스탈 느낌 (커스텀 아이콘) |
| 🌊 오션 블루 | 시원한 파란 톤 |
| 🌿 포레스트 그린 | 자연스러운 초록 톤 |

선택한 테마는 브라우저에 저장되어 다음에 열어도 유지됩니다.

## ❓ 자주 묻는 질문

### 비용이 드나요?
**아닙니다.** 모든 것이 무료입니다. Firebase 무료 한도: 동시 접속 100명, 저장 1GB, 월 10GB 전송.

### 관리자 비밀번호를 잊으면?
Firebase Console → Realtime Database에서 해당 투표의 `adminPw` 값을 직접 확인하거나 삭제할 수 있습니다.

### 초대 링크 없이도 투표에 참여할 수 있나요?
홈 화면의 "진행 중인 투표" 목록에서도 접근할 수 있습니다. 초대 링크는 편의 기능입니다.

### 모바일에서도 되나요?
**네!** 반응형 디자인으로 스마트폰, 태블릿, PC 모두 지원합니다.

### 투표를 완전히 삭제하고 싶어요
Firebase Console → Realtime Database → 데이터 탭에서 해당 투표를 삭제하면 됩니다.

## 🔧 문제 해결

| 증상 | 해결 방법 |
|------|-----------|
| "Firebase 설정 필요" 화면 | `firebaseConfig`에 설정값이 들어갔는지 확인 |
| 데이터 저장 안 됨 | Firebase 규칙 탭에서 3단계의 규칙이 적용되었는지 확인 |
| `databaseURL` 에러 | `firebaseConfig`에 `databaseURL` 줄 포함 여부 확인 |
| 30일 후 작동 안 됨 | 테스트 모드 만료. 3단계 규칙으로 재설정 |
| 마감 버튼이 안 눌림 | 관리자 비밀번호가 설정된 투표입니다. 비밀번호를 입력하세요 |

## ✏️ 기본 명단·예시 이름 수정하기

코드를 다운로드하지 않고도 **GitHub 웹에서 바로 수정**할 수 있습니다.

1. GitHub 저장소에서 `index.html` 파일을 클릭합니다
2. 오른쪽 상단의 **✏️ 연필 아이콘** (Edit this file)을 클릭합니다
3. `Ctrl+F` (또는 `Cmd+F`)로 아래 부분을 검색합니다:

```javascript
const DEFAULT_MEMBERS=["석리송","송리석","리석송","송석리"];
```

4. 따옴표 안의 이름을 원하는 멤버로 바꿉니다:

```javascript
const DEFAULT_MEMBERS=["김영희","이철수","박민수","정수진"];
```

5. 마찬가지로 `textarea` 태그의 `placeholder` 부분도 검색하여 예시 이름을 수정할 수 있습니다
6. 수정 후 오른쪽 상단의 **"Commit changes"** 버튼을 클릭하면 자동 반영됩니다

> 💡 GitHub Pages는 커밋하면 1-2분 내에 자동 배포됩니다. 새로고침하면 바로 적용!
